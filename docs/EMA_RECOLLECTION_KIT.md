# Ecological Momentary Assessment (EMA) Re-Collection Kit
## Standard Human Study Protocol, Collector Harness & Evaluation Guide

> **PROTOCOL STATUS:** `REQUIRES HUMAN: Collect empirical data with ≥ 3 human participants before final viva`  
> **ETHICAL COMPLIANCE:** Voluntary academic peer evaluation; 100% on-device local execution; zero telemetry or external transmission; immediate disposal of raw audio/video frames.

---

## 1. Executive Summary & Purpose

Earlier test runs and preliminary documentation utilized synthetic assessment data generated by `scripts/run_ema_validation.py` for pipeline validation. In accordance with strict empirical validation standards, **all synthetic percentage claims (77.8% exact / 100% one-tier agreement) have been expunged from the submission reports and marked as `NOT COLLECTED / REQUIRES HUMAN STUDY`**.

This kit provides the complete, turnkey software harness and standardized experimental protocol for the team (Batch 14) to conduct a genuine, human-grounded evaluation prior to the project viva.

---

## 2. Participant Privacy & Ethical Safeguards

1. **Local Boundary:** All facial action unit (AU) extraction, vocal acoustic DSP, and Gemma 4 SLM reasoning execute entirely in-process on the local workstation. No audio, video, or feature vectors leave `127.0.0.1`.
2. **Ephemeral Media:** Webcam frames and audio buffers are analyzed strictly in volatile RAM and immediately discarded. No video files or raw audio clips are written to disk.
3. **Derived Metrics Only:** The only persistent data stored is the local SQLite history (`shared_state/wellness_history.db`) and participant EMA survey responses (`shared_state/ema_records.json`).
4. **Voluntary Participation:** Participants may pause, skip conditions, or withdraw at any moment without penalty.

---

## 3. Workstation & Environmental Prerequisites

- **Workstation:** Local host with webcam, microphone, and NVIDIA GPU (or CPU fallback).
- **Active System:** Run `cd parlor-main-main; .\start.ps1` in a PowerShell terminal. Verify that `http://127.0.0.1:8000` is active and the live camera feed is tracking.
- **Lighting:** Standard indoor office lighting (~300–500 lux). Avoid harsh backlighting behind the user.
- **Microphone:** Built-in laptop microphone or standard USB headset positioned ~15–30 cm from mouth.

## 4. 20-Minute Standardized Experimental Protocol

Each participant undergoes a 20-minute session comprising four 5-minute capture windows designed to elicit distinct emotional and cognitive stress states:

| Condition ID | Name | Duration | Activity Protocol | Primary Modalities | Expected Stress Tier |
|:---|:---|:---:|:---|:---|:---:|
| **Condition 1** | **Quiet Focused Work (Baseline)** | 5 min | Participant reads technical papers or code documentation quietly. No speaking. Natural posture. | Facial AUs (Brow relaxation, blink rate) | **Tier 0** (Baseline / Calm) |
| **Condition 2** | **Active Conversational Speech** | 5 min | Participant talks aloud, explaining a project topic or conversing casually with Parlor. | Facial AUs + Vocal Prosody (F0, Energy) | **Tier 0 / Tier 1** (Moderate engagement) |
| **Condition 3** | **Acute Timed Cognitive Stressor** | 5 min | Participant completes a timed rapid mental arithmetic or Stroop color-word interference task under a strict countdown. | Facial (AU04 brow furrow, AU07 lid tight) + Vocal (jitter, pitch shift) | **Tier 2** (High Stress / Fatigue) |
| **Condition 4** | **Occluded / Single-Modality Fallback** | 5 min | Webcam is partially covered or lighting dimmed (<50 lux). Participant answers questions under acoustic-only tracking. | Audio DSP only (`face_detected: False`) | **Tier 1 / Tier 2** (Fallback mode) |

## 5. The 3-Item EMA Survey Instrument

Immediately following each 5-minute window, the investigator prompts the participant using the standardized 3-item EMA instrument (adapted from PSS-10 and WESAD validation literature):

```text
Item 1: Emotional Tension
"How tense, anxious, or stressed did you feel during the last capture window?"
[1] Completely Calm / Relaxed
[2] Mildly Aware / At Ease
[3] Moderately Tense
[4] Noticeably Stressed
[5] Extremely Tense / Agitated

Item 2: Perceived Demand
"How overwhelmed did you feel by your current activity?"
[1] Fully in Control
[2] Manageable
[3] Slightly Strained
[4] Struggling to Keep Pace
[5] Overwhelmed / Frustrated

Item 3: Somatic Physical Tension
"Did you notice physical tension (brow furrowing, jaw clenching, rapid breathing)?"
[1] None
[2] Slight / Fleeting
[3] Mild Physical Tension
[4] Distinct Muscle Tightness
[5] Severe / Persistent Strain
```

### Composite Score & Ground-Truth Tier Mapping
$$\text{Composite EMA Score} = Q_1 + Q_2 + Q_3 \quad (\text{Range: } 3 \text{ to } 15)$$

- **Composite 3 – 5:** $\rightarrow$ **Tier 0 (Low Stress / Baseline)**
- **Composite 6 – 10:** $\rightarrow$ **Tier 1 (Moderate Stress / Elevated Tension)**
- **Composite 11 – 15:** $\rightarrow$ **Tier 2 (High Stress / Burnout Risk)**

## 6. Step-by-Step Operator Instructions

### Step 1: Start Parlor Server
In Terminal 1:
```powershell
cd parlor-main-main
.\start.ps1
```
Open browser to `http://127.0.0.1:8000`. Ensure camera and mic permissions are allowed and the diagnostic status bar displays green indicators.

### Step 2: Launch the Interactive EMA Collector
In Terminal 2:
```powershell
cd parlor-main-main
uv run python scripts/ema_collector.py
```
Follow the interactive prompts:
1. Enter Participant ID (e.g., `P01`, `P02`, `P03`).
2. Select experimental condition (1 to 4).
3. Allow the participant to perform the activity for 5 minutes.
4. Press `[Enter]` upon completion of the window.
5. Enter the participant's ratings for Q1, Q2, and Q3.
6. The script automatically fetches the timestamp-aligned assessment from `shared_state/wellness_history.db`, checks agreement, and appends the paired trial to `shared_state/ema_records.json`.

Repeat across all 4 conditions for at least 3 distinct human participants ($N \ge 12$ paired observation trials).

### Step 3: Run the Empirical Evaluation Script
After completing all collection sessions, generate the official empirical accuracy report:
```powershell
uv run python scripts/evaluate_ema.py
```
This script computes:
- Exact Tier Agreement Percentage
- $\pm 1$-Tier Clinical Tolerance Percentage
- Normalized Confusion Matrix
- Mean absolute error across stress tiers

Save the terminal output to `evidence/ema_human_evaluation.txt` and reference the resulting verified figures in your final presentation.
